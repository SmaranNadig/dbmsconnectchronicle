How to interpret a run

Real FlyWire synapse counts weight the L1/L2 → intermediate neurons → T4/T5 pathways. A simplified rate model supplies input polarity, delays and coincidence responses. A linear decoder learns from 48 separate calibration scenes and stays fixed across interventions. A conventional pixel correlator reads the same images as an engineering reference.

Compare seeds, patch sizes and shuffled controls before attributing performance to particular wiring. The replay shows simulated activity and steering commands in grid units.
