How the model works

    

      
Odors excite a sparse population
Generated activity arrives at olfactory projection channels. FlyWire synapse weights map those channels to Kenyon cells. The model passes activity above the upper-quartile cutoff.

      
Feedback modifies output gains
Reward weakens active connections to MBON01 in the right medial lobe. Training without reward can partially restore gains. The dopamine pathway supplies a scalar to the modeled update.

      
Choice reads the current memory
The model compares the reduction in MBON01 drive for each odor. A larger reduction raises that odor’s preference. A stored random draw then produces one choice.

      
Forks make experiments comparable
A new branch starts with the same gain vector and shared trial schedule. Gain changes are stored by real connection ID. Compare with frozen, unpaired, rewired, or silenced controls to test what shaped the result.
